# Known issues

Honesty rule: anything that does not work is listed in this file as NOT WORKING, and the
dashboard shows "not available" for it. Nothing is hidden, faked or quietly dropped. If a result
is partial or synthetic, say so here and in the UI.

Status words: **NOT WORKING** (fails), **limit** (works, with a stated restriction), **partial**.

| Item | Status | Detail | What to try next | Owner area |
| --- | --- | --- | --- | --- |
| MPS scaling, bond dimension 2 and 4 | limit | Aer 0.18.2 on Windows crashes (access violation 0xC0000005, heap corruption 0xC0000374, fast-fail 0xC0000409) or hangs on some circuits at bond dimension 2 or 4. It is deterministic per circuit and depends on how the circuit is compiled; neither `mps_lapack=True` nor a larger truncation threshold removes it (`mps_lapack` even fails at bond dimension 64). Every point is therefore retried once with the circuit routed to a line; the note of each such point says so, and a point that fails both ways carries no numbers (`results/scaling.json` notes). Evidence: `docs/MPS_DIAGNOSTICS.md`. | Run the stage on Linux (CI) to see whether the crashes are Windows-only; report upstream to qiskit-aer with the probe's reproducer. | Area 1 |
| MPS scaling, qubit layout | limit | The old note said the "interleaved" layout crashes at 16 qubits. In a fresh process per run it did not crash at any bond dimension tried (probe, `docs/MPS_DIAGNOSTICS.md`), so the session-2 crash could not be reproduced; the likely causes are a small bond dimension or state left in the long-lived worker, and the retry above covers both. Layouts that put each feeder's hours side by side do not beat the original layout either (fidelity within a few percent at bond dimension 64), so the stage keeps the original layout. | None needed. | Area 1 |
| MPS fidelity above 20 qubits | limit | Fidelity is measured against the exact statevector of the same circuit, so only up to 20 qubits. An untruncated MPS reference (bond dimension 256) did not finish in 150 s at 28 and 36 qubits. Above 20 qubits the curve reports plan quality and valid share only, and `fidelity` is null. | A cheaper exact reference (for example a GPU statevector at 28 to 30 qubits). | Area 1 |
| MPS at 54 and 72 qubits | limit | Bond dimension 64 or less is not enough there: many samples are invalid plans and the quality does not settle as the bond dimension grows (`results/scaling.json`). It is shown as measured, not hidden. | Bond dimensions 128 and 256 on a bigger machine. | Area 1 |
| MPS memory pre-check | limit | Aer's MPS memory estimate is far too high (28 qubits: "57345 MB required"), so `max_memory_mb` is raised to 4 TB. Real use is bounded by the bond dimension; each point still runs in an isolated worker with a time limit. | None needed unless a point is killed for memory. | Area 1 |
| Risk block size | limit | The spec asks for a 4-6 feeder block. The risk stage uses the 8-feeder replay cluster, because with 4-6 feeders the uncovered shortfall is zero in every residual scenario. The loss is the MW the peak-hour plan does not cover. | Use a larger residual spread or smaller feeders to make a 4-6 feeder block meaningful. | Area 1 |
| Pareto point at fairness weight 1.0 | limit | The QAOA decision rule (best valid of 256 shots) returns cost 11.0 where the exact optimum is 10.5. The other 5 weights match exact. Shown as "matches_exact: false". | More shots or p=3 for the decision rule. | Area 1 |
| Replay frames worse than exact | limit | 3 of 12 frames (16:00, 17:00, 19:00) commit a plan whose window cost is above the exact optimum. All 12 plans are valid and pass the audit. | Same as above: more shots or layers in `solve_window`. | Area 1 |
| Cross-machine reproducibility | limit | Fixed seeds reproduce results on one machine. COBYLA angles differ in the 4th decimal between machines (BLAS/OS), so sampled counts can differ slightly across machines. | None; tests compare runs on the same machine. | Area 1 |
| GAS runtime on StatevectorSampler | limit | GroverOptimizer with qiskit's StatevectorSampler took 258 s for 10 runs. The stage uses the Aer sampler (9.4 s for 20 runs). | Keep the Aer sampler. | Area 1 |
