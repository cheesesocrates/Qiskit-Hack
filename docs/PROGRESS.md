## Decisions made

Session 1 (do not re-litigate):
- Areas talk only through `results/*.json` + `schemas/`. Area 1 never imports Area 2 code;
  it reads the QUBO from `results/plans/<scenario>.json` (`instance.qubo.terms`, unweighted).
- `bits` in results are index-ordered (`bits[t*N+f]`), the reverse of Qiskit count keys.
- Circuits use a compact register (no qubit for protected feeders): 8x3 gives 18 qubits.
- The replay calls the quantum solver as a subprocess through JSON files, falling back to exact per frame.
- Decision rule for a QAOA plan: best valid sample among 256 shots.
- UI: IBM Plex Sans/Mono, dark slate, colour only for feeder state, one iris accent.
- Proof checks: tests marked `@pytest.mark.check(id, name)` are merged into `results/checks.json`.

Session 2:
- Python 3.11.9 installed with `py install 3.11` (only 3.14 was present). Pins unchanged.
- GAS uses the Aer SamplerV2 with a level-1 pass manager (30x faster than StatevectorSampler).
  Objective coefficients are scaled by 6 to integers (exact, rounding error 3.6e-15); 20 runs.
- MPS scaling uses the default qubit layout and a raised `max_memory_mb`: the interleaved layout
  crashes Aer on Windows at 16 qubits, and Aer's MPS memory pre-check overestimates by orders of
  magnitude (28 qubits: "57345 MB required", real run takes about 1 s).
- Risk loss = shortfall not covered by the peak-hour plan (MW), from the 8 forecast residual
  bins (3 qubits). The block is the 8-feeder replay cluster, not a 4-6 feeder block, because a
  smaller block makes the loss zero in every scenario.
- Risk circuits are transpiled to u/cx before IAE because Aer 0.18.2 segfaults on the raw ops.
- `results/replay.json` comes from `--solver quantum` (the default when `run_quantum.py` exists).
- `ui/js/rules.js` now ports `src/audit/rules.py` exactly (ledger counts toward daily hours,
  one consecutive check per feeder, same score), so the browser re-check matches the stored audit.
- UI smoke test is Node + CDP with no npm packages; the pytest wrapper skips without Node 22+ or a browser.
- `pytest` rewrites `generated_at` in the classical results files; the changes are committed.
- Q07 reproducibility holds within one machine; angles differ in the 4th decimal across machines.
